# Bloomy Hook ✿  
**Where yarn meets heart.**  

Bloomy Hook is a premium, handcrafted crochet business website. Designed to be elegant, cozy, and high-end, it allows customers to browse beautiful handmade items like flowers, keychains, and home decor, view them in compact popups, and place orders effortlessly via WhatsApp.  

---

## 🌟 Tech Stack  

**Frontend:**  
- Semantic HTML5  
- Vanilla CSS3 (Custom Design System)  
- Modern Vanilla JavaScript  

**Tools & Libraries:**  
- [FontAwesome 6.5.1](https://fontawesome.com/) for icons  
- [Google Fonts](https://fonts.google.com/) — *Dancing Script* & *Inter*  
- [Formspree](https://formspree.io/) for contact form backend  

---

## ✨ Key Features  

- **Interactive Shop 🧶**  
  Filter products by categories: Flowers, Keychains, Home Decor, and Plushies.  

- **Dynamic Product Modals ✿**  
  Smooth side-by-side popups for viewing product details.  

- **Dynamic Pricing Engine 💰**  
  JS-powered price calculator for custom bouquets, e.g., *Blushing Rose Bouquet*.  

- **One-Click WhatsApp Ordering 📲**  
  'Order Now' buttons open WhatsApp with pre-filled product messages.  

- **Premium Contact Form ✨**  
  Includes a phone number field and a custom 'Success' popup with a high-end checkmark animation.  

- **Responsive Design 📱**  
  Fully optimized for mobile, tablet, and desktop screens.  

- **Minimalist 'About' Layout 🖋️**  
  Compact storytelling page that shares the brand’s mission and story.  

---

## 🏛️ Website Architecture  

- **index.html** — Hero section with featured creations.  
- **shop.html** — Full product catalog with filtering.  
- **about.html** — Story and mission of Bloomy Hook.  
- **contact.html** — Custom form integrated with Formspree.  

---

## ⚙️ Installation / Setup  

Bloomy Hook is a fully static website. To view it:  

1. Download the repository.  
2. Open `index.html` in any modern browser.  
3. *(Optional)* Use **Live Server** in VS Code for real-time development.  

No backend setup is required.
